# Opencode Insight (Visualization Tool)

This is the frontend component of **InsightAgents**. It provides a high-fidelity dashboard for analyzing Opencode agent session logs (`.jsonl`).

## Features

- **Interactive Charts**: Powered by Recharts for token and context analysis.
- **Drill-down Inspection**: Click on context growth bars to see the specific tool execution that caused the growth.
- **Rich Conversation UI**: View agent-user interactions with detailed tool input/output blocks.
- **Token Stack View**: Understand the breakdown between billed input, cached context, and output tokens.

## Development

### Prerequisites
- Node.js (v18+)
- npm or pnpm

### Setup
```bash
npm install
```

### Run
```bash
npm run dev
```

### Build
```bash
npm run build
```

## Usage
Once the app is running, upload a `.jsonl` file generated by the `opencode-vis-plugin`. These files are typically found in the `.opencode/sessions/` directory of your agent project.
